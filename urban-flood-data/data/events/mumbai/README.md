# Historical Rainfall Events — Mumbai

This directory indexes historical extreme rainfall events for Mumbai used for hydrodynamic model validation and deep learning replay.

## Events Catalogued

### 1. `MUM_20050726_DELUGE` (26–27 July 2005)
- **Total 24h Rainfall:** 944.2 mm (Santa Cruz)
- **Peak Intensity:** ~190 mm/hr
- **Mechanism:** Offshore convective vortex anchored by Western Ghats topography.
- **Hydrological Impact:** Widespread flooding along the Mithi River corridor (BKC, Kurla, Kalina, Saki Naka) and suburban lowlands.

### 2. `MUM_20190702_MONSOON` (1–2 July 2019)
- **Total 24h Rainfall:** 375.2 mm
- **Peak Intensity:** ~78.5 mm/hr
- **Mechanism:** Severe offshore convective squall line.
- **Hydrological Impact:** Severe waterlogging at King's Circle, Hindmata, Gandhi Market, Sion, and Dahisar.

### 3. `MUM_20230725_CYCLIC` (25–26 July 2023)
- **Total 24h Rainfall:** 218.6 mm
- **Peak Intensity:** ~64 mm/hr
- **Mechanism:** Active monsoon low-pressure system coinciding with afternoon spring high tide (>4.2 m).
- **Hydrological Impact:** Coastal outfall drowning and inland backwater surcharge.
